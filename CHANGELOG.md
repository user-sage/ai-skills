# Changelog

Each skill carries its own version in its SKILL.md. This file records every release of the pack, including any skill that is changed or retired.

## 1.0.0, November 2026

The first release, with seven skills in the order a study runs. In Claude Code you can install the whole set as one plugin, or any skill by itself.

- Plan a study (`plan-a-study`), version 1.0.0.
- Write a screener (`write-a-screener`), version 1.0.0.
- Write an interview guide (`write-an-interview-guide`), version 1.0.0.
- Audit a study before launch (`audit-a-study`), version 1.0.0.
- Analyze findings (`analyze-findings`), version 1.0.0.
- Ask about your research (`ask-your-research`), version 1.0.0.
- Share findings as a readout (`share-findings-readout`), version 1.0.0.

All seven skills work in User Sage through MCP, and all seven work as a download or as a Claude Code plugin.
